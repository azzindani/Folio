# One-shot benchmark — briefs

Hand-written, the way people actually ask (see the harness rule: human voice,
varied care and length, no tool names, never generated). A builder sees ONLY the
text under a brief's heading, after one constant runner line naming its project.
The `kind` line is metadata for scoring and is never shown.

Scored on completion, diagnose/review findings, a looked-at visual score, and the
DIVERSITY of the set — never on conformance to any preset or expected look.
